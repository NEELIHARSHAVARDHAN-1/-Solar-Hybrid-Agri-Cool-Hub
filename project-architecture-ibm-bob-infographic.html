IBM Bob — AI Software Engineering Assistant

IBM Bob lives inside the IDE and reads every file in the repository. It planned the architecture, wrote production code across all 4 technology layers, diagnosed hardware and software bugs, and authored all documentation — making a 4-specialist project achievable by a small student team.

🗺️
Planning & Architecture
Before any code was written

Specified all MQTT topics, database schema, and REST API contracts
Designed the two-tier WARNING / CRITICAL alert classification model
Planned offline deduplication strategy using (device_id, timestamp) unique key
💻
Code Generation
Across all 4 tech stacks
Generated all 18 C++ firmware modules — sensors, Wi-Fi, MQTT, buffer, GPS, RTC
Built the entire FastAPI backend — routes, services, MQTT client, SSE stream
Wrote the React SSE hook using useSyncExternalStore for real-time cards
Generated Retrofit interface and all Android fragments with ViewBinding
Wrote SVG radial gauge component with threshold colour transitions
🐛
Debugging
Critical bugs caught & fixed
Silent data loss: str(bytes) → .decode() fix in MQTT handler — all data was being discarded
Hardware damage prevented: Specified 10kΩ/20kΩ voltage divider for MQ sensor ADC pins
Android crash: Fixed NullPointerException via ViewBinding onDestroyView pattern
DB pool exhaustion: SSE generator restructured to release connections before sleep
GPS freeze: Rewrote blocking GPS read as non-blocking byte-by-byte UART drain
✅
Testing & Documentation
Quality + knowledge transfer
Wrote 24 pytest tests on in-memory SQLite — no real DB or broker needed
Tests cover schema validation, alert engine, deduplication, all API endpoints
Authored 8 documentation files: wiring, API, deployment, config, troubleshooting
Wrote idempotent schema migrations — auto-run at startup, zero data loss
