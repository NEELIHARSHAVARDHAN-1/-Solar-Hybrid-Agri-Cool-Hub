# Deployment Guide — Solar Hybrid Agri Cool Hub

## 1. HiveMQ Cloud Setup (MQTT Broker)

1. Go to https://www.hivemq.com/mqtt-cloud-broker/
2. Create a free account and start a free cluster.
3. Note the **Host** (e.g. `abc123.s2.eu.hivemq.cloud`).
4. Under **Access Management**, create a user with a username and password.
5. Copy these values into:
   - `firmware/src/config_secrets.h` (`MQTT_HOST`, `MQTT_USER`, `MQTT_PASSWORD`)
   - `backend/.env` (`MQTT_HOST`, `MQTT_USER`, `MQTT_PASSWORD`)

Default port: **8883** (TLS). Do not use port 1883.

---

## 2. PostgreSQL Setup

### Option A — Local Development (Docker Compose)

```bash
cd backend
docker-compose up -d
```

This starts PostgreSQL on `localhost:5432`, creates the `agrihub` database,
and runs `init_db.sql` to create tables automatically.

### Option B — Cloud PostgreSQL (Railway, Render, Supabase, Neon)

1. Create a PostgreSQL database on your chosen provider.
2. Copy the connection string into `backend/.env` as `DATABASE_URL`.
   Use the `postgresql+asyncpg://` scheme, not `postgresql://`.
3. Run the init script manually:
   ```bash
   psql "YOUR_CONNECTION_STRING" -f backend/init_db.sql
   ```
   Or let the backend create tables on first startup (SQLAlchemy `create_all`).

## 3. Backend Deployment

### Local Development

```bash
cd backend
cp .env.example .env
# Edit .env with real credentials
pip install -r requirements.txt   # use Python 3.10 or 3.11
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

### Railway Deployment

1. Push your repository to GitHub.
2. Create a new Railway project → Deploy from GitHub repo.
3. Set Root Directory to `backend`.
4. Add all environment variables from `.env.example` under **Variables**.
5. Railway auto-detects `requirements.txt` and starts `uvicorn`.
6. Set the start command if needed: `uvicorn app.main:app --host 0.0.0.0 --port $PORT`

### Render Deployment

1. New Web Service → connect GitHub repo.
2. Root Directory: `backend`.
3. Build command: `pip install -r requirements.txt`
4. Start command: `uvicorn app.main:app --host 0.0.0.0 --port $PORT`
5. Add all environment variables from `.env.example`.

## 4. Verify Backend

```bash
curl https://YOUR_BACKEND_URL/health
# Expected: {"status":"ok"}

curl https://YOUR_BACKEND_URL/devices
# Expected: [] (empty array until device connects)
```

Interactive API docs (auto-generated by FastAPI):
```
https://YOUR_BACKEND_URL/docs
```

## 5. Flutter App Deployment

```bash
cd app
flutter pub get
flutter run           # development on emulator/device
flutter build apk     # release APK
```

In the app:
1. Open **Settings**.
2. Enter `https://YOUR_BACKEND_URL` (no trailing slash).
3. Tap **Save**.

## 6. Firmware Deployment

See [`firmware/FLASH_INSTRUCTIONS.md`](../firmware/FLASH_INSTRUCTIONS.md) for full steps.

Quick summary:
1. Copy `firmware/src/config_secrets.h.example` → `firmware/src/config_secrets.h`.
2. Fill in SSID, password, HiveMQ host, user, password.
3. Open `firmware/firmware.ino` in Arduino IDE.
4. Select board: **ESP32S3 Dev Module**, Flash Size: **16MB**.
5. Click **Upload**.
